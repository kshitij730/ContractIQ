# Security Policy

## Supported Versions

ContractIQ is currently maintained on the latest `main` branch.

## Reporting a Vulnerability

Please do not open public issues for sensitive vulnerabilities.

Instead:

1. Email the maintainer directly or use GitHub private vulnerability reporting.
2. Include reproduction steps, affected area, and severity estimate.
3. Allow time for triage before public disclosure.

## Security Scope

The most sensitive areas in this project are:

- authentication and token handling
- contract upload and file processing
- LLM prompt handling and outbound integrations
- dependency supply chain health
- exported report generation
